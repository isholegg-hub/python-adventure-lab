# Python Adventure Lab — Українська документація

## 1. Що це?

Python Adventure Lab — це освітній проєкт у вигляді пригодницької браузерної гри для дітей віком 10+, який дозволяє в легкій ігровій формі вивчати основи програмування на Python, об'єктно-орієнтоване програмування (ООП), а також базові принципи веб-розробки на фреймворку Flask. Гравець проходить шлях від Села через Ліс та Печеру до Стародавнього Замку, виконуючи дії та приймаючи рішення. У процесі вивчення можна змінювати код гри, додавати нові локації, предмети та персонажів.

## 2. Для кого цей проект?

- **Діти 10+ років** — перше знайомство з програмуванням через цікаву гру;
- **Підлітки** — поглиблення знань Python та освоєння веб-розробки;
- **Дорослі початківці** — швидке засвоєння баз Python, ООП та Flask на прикладі повного проєкту;
- **Вчителі та тренери** — готовий навчальний матеріал для уроків інформатики та курсів програмування.

## 3. Які технології використані?

- **Python 3.11+** — основна мова програмування, на якій написана логіка гри;
- **Flask ≥ 3.0** — легкий веб-фреймворк, який відповідає за роботу сервера, маршрутизацію (routes) та сесії;
- **Jinja2** — шаблонізатор, що вбудований у Flask і дозволяє вставляти змінні Python у HTML-сторінки;
- **pytest ≥ 8.0** — фреймворк для написання та запуску автоматизованих тестів;
- **HTML5 / CSS3** — розмітка та стилізація веб-інтерфейсу гри;
- **python-dotenv ≥ 1.0** — бібліотека для завантаження конфігурації з файлу `.env`.

## 4. Як встановити?

Повна покрокова інструкція для Windows, macOS та Linux, зокрема встановлення Python і пакетів, запуск тестів та розв'язання типових проблем, доступна в [інструкції зі встановлення, запуску та збірки](setup.md). Окремого етапу компіляції Flask-застосунок не має.

## 5. Як запустити?

Виконайте команди для своєї операційної системи з [повної інструкції](setup.md). Успішний запуск підтверджує рядок `Running on http://127.0.0.1:5000`; відкрийте цю адресу у браузері. Щоб зупинити сервер, натисніть у терміналі `Ctrl+C`.

## 6. Як грати?

1. **Старт** — на головній сторінці введіть ім'я гравця та натисніть «Start Game». Ви опинитеся у **Village** (Селі).
2. **Village → Forest** — оберіть дію «Go to Forest», щоб вирушити в Ліс.
3. **Forest → Cave** — у Лісі перейдіть у Печеру («Enter Cave»).
4. **У Печері** є два шляхи:
   - **Explore the cave carefully** — обстежити печеру та знайти **Castle Key** (ключ від замку), +30 score.
   - **Fight the monster** — побороти монстра: ви отримаєте пошкодження (-35 HP), але заробите +50 score та мечу **Hero's Sword**.
5. **Поверніться у Forest** — оберіть «Return to Forest».
6. **Forest → Castle** — з'явиться дія **«Journey to the Ancient Castle»**. Перейдіть нею до Стародавнього Замку.
7. **Перемога** — у Замку використайте дію **«Use the Castle Key»**. Якщо ключ у вас є, ви виграєте +100 score та завершите гру.
8. **Підказки**:
   - Купуйте **Healing Potion** у Shop за 10 score, щоб відновлювати здоров'я (Use Potion додає +40 HP).
   - Постійно стежте за рівнем здоров'я (HP): якщо він впаде до 0, гра закінчиться поразкою.
   - У Лісі можна шукати скарби («Search the forest») для додаткових score та рандомного предмета.

## 8. Рівні навчання

### Level 1 — Основи Python (змінні, списки, словники, умовні оператори)
- Змінити початкове здоров'я гравця (напр. 100 → 120) у `game/player.py`;
- Додати новий предмет (напр. «coin») до словника `ITEMS` у `game/data.py`;
- Додати нову локацію (напр. «River») до `LOCATIONS` у `game/data.py`;
- Додати просту дію (напр. «Rest» у Village, яка додає 5 HP).

### Level 2 — Об'єктно-орієнтоване програмування (ООП)
- Створити новий тип предмета **Armor** (броня), який зменшує отримані пошкодження;
- Додати клас **NPC** (неігровий персонаж) з власними атрибутами та методом `talk()`;
- Реалізувати клас **Enemy** (ворог) з `name`, `health`, `attack` для справжніх ходових боїв.

### Level 3 — Flask та Web
- Додати нову Flask-сторінку `/about` з описом проєкту;
- Додати нову дію у грі з окремою HTML-формою (напр. «Trade» з Merchant);
- Змінити відображення статистики гравця: додати стовпець «Level» або «Experience»;
- Змінити дизайн сторінки через CSS: кольори, шрифти, анімації.

### Level 4 — Advanced (просунуті теми)
- Підключити **PostgreSQL** замість Flask-session для збереження стану гри;
- Додати реєстрацію та авторизацію користувачів (users table, login/logout);
- Зберігати збереження гри (saves) у базі даних і дозволяти продовжувати з будь-якого місця;
- Реалізувати **REST API** (`/api/game`, `/api/action`) для зовнішніх клієнтів;
- Додати інтерактивність через **JavaScript / AJAX** (оновлення гри без перезавантаження сторінки);
- Реалізувати **лідерборд** (топ-10 гравців за score) з таблицею результатів;
- Додати декілька окремих пригод (карта світу, кілька замків, квести);
- Створити **адмін-панель** для управління локаціями, предметами та монстрами.

## 9. Можливості розширення (дорожня карта)

- **V1 (Flask Session)** — поточна версія: Flask session, дані в пам'яті, JSON-сералізація;
- **V2 (PostgreSQL)** — перехід на PostgreSQL через SQLAlchemy, таблиці users, game_saves;
- **V3 (REST API)** — розділення бекенда (JSON API) та фронтенда, swagger-документація;
- **V4 (React / JS)** — інтерфейс на React / Vue, SPA з AJAX-запитами до Flask API;
- **V5 (Auth + Users)** — Flask-Login, JWT, особисті кабінети, історія ігор;
- **V6 (Docker / Deploy)** — Dockerfile + docker-compose, деплой на Heroku / Render / Fly.io;
- **V7 (CI/CD)** — GitHub Actions, автотести pytest, авто-деплой, літеринг (flake8, black).
