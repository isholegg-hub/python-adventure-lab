# Python Adventure Lab: інструкція зі встановлення, запуску та збірки

Ця інструкція допоможе пройти шлях від завантаження проєкту до робочої гри у браузері. Є кроки для Windows, macOS та Linux.

## Що означає «збірка» цього проєкту

Python Adventure Lab — це вебзастосунок на Flask. Окремо компілювати його або створювати інсталятор чи файл `.exe` не потрібно. Достатньо завантажити вихідний код, створити ізольоване середовище Python, встановити потрібні пакети та запустити локальний вебсервер. Для першого встановлення пакетів потрібен інтернет; під час гри зовнішні сервіси не використовуються.

## Що знадобиться

- Python версії 3.11 або новішої.
- Веббраузер.
- Інтернет для першого встановлення пакетів Python.
- Термінал: PowerShell у Windows або Terminal у macOS/Linux.

Git не потрібен, якщо завантажити проєкт ZIP-архівом. Встановлювати Flask глобально не потрібно.

## 1. Завантажте та відкрийте проєкт

1. Завантажте проєкт ZIP-архівом або отримайте його копію від учителя.
2. Розпакуйте ZIP-архів. Не запускайте команди з попереднього перегляду архіву.
3. У VS Code виберіть **File > Open Folder** та відкрийте теку проєкту. Це тека, у якій лежать `requirements.txt`, `app.py` та теки `game`, `templates` і `static`.
4. Відкрийте термінал у VS Code через **Terminal > New Terminal**. Термінал має бути відкритий у теці проєкту. Перевірте це командою:

   ```text
   dir
   ```

   У macOS/Linux виконайте `ls`. Переконайтеся, що у списку є `requirements.txt`. Якщо його немає, відкрийте внутрішню теку проєкту, створену під час розпакування ZIP.

## 2. Перевірте Python

У терміналі перевірте, чи встановлено Python:

**Windows (PowerShell):**

```powershell
python --version
```

Якщо команда не розпізнається, спробуйте Python Launcher:

```powershell
py -3 --version
```

**macOS/Linux:**

```bash
python3 --version
```

Потрібна версія 3.11 або новіша. Якщо Python у Windows відсутній, встановіть його з [python.org](https://www.python.org/downloads/) та позначте **Add python.exe to PATH** у вікні інсталятора. Потім закрийте й знову відкрийте VS Code та повторіть перевірку. Якщо команда `python` відкриває Microsoft Store, вимкніть псевдоніми запуску програм `python.exe` і `python3.exe` у налаштуваннях Windows або використайте `py -3`, якщо він працює.

## 3. Створіть ізольоване середовище та встановіть пакети

Виконуйте команди з теки проєкту. Вони запускають Python безпосередньо з `.venv`, тому активувати середовище не обов'язково.

**Windows (PowerShell):**

```powershell
python -m venv .venv
```

Якщо команда `python` недоступна, але спрацювала перевірка `py -3 --version`, замість неї створіть середовище так:

```powershell
py -3 -m venv .venv
```

Після цього встановіть пакети:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**macOS/Linux:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Встановлення може тривати хвилину. Flask, pytest і python-dotenv встановляться в середовище цього проєкту, а не до системного Python. Тека `.venv` зберігається лише на вашому комп'ютері; її не потрібно надсилати вчителю або додавати до ZIP-архіву проєкту.

## 4. Запустіть гру

**Windows (PowerShell):**

```powershell
.\.venv\Scripts\python.exe app.py
```

**macOS/Linux:**

```bash
.venv/bin/python app.py
```

Дочекайтеся рядка на зразок:

```text
Running on http://127.0.0.1:5000
```

Відкрийте у браузері адресу [http://127.0.0.1:5000](http://127.0.0.1:5000). Під час гри не закривайте термінал. Щоб зупинити сервер, виберіть вікно термінала та натисніть **Ctrl+C**.

Це локальний сервер для розробки, призначений для роботи на вашому комп'ютері, а не для публікації гри в інтернеті. За замовчуванням застосунок запускається в режимі налагодження; не відкривайте його для публічної мережі.

## 5. Запустіть тести (необов'язково)

Зупиніть сервер клавішами **Ctrl+C** або відкрийте другий термінал у теці проєкту.

**Windows (PowerShell):**

```powershell
.\.venv\Scripts\python.exe -m pytest -v
```

**macOS/Linux:**

```bash
.venv/bin/python -m pytest -v
```

Pytest виведе результати перевірок у терміналі. Щоб знову запустити гру, виконайте команду з кроку 4.

## Поширені проблеми

### `python` не знайдено або Windows пропонує відкрити Microsoft Store

Встановіть Python 3.11 або новіший з [python.org](https://www.python.org/downloads/), позначте **Add python.exe to PATH** та перезапустіть VS Code. Якщо команда `py -3 --version` працює, на кроці 3 створіть середовище командою `py -3 -m venv .venv`. Якщо й далі відкривається Microsoft Store, вимкніть псевдоніми запуску Python у налаштуваннях Windows.

### `No module named 'flask'` або `No module named 'dotenv'`

Встановіть пакети командою з кроку 3, використовуючи Python із `.venv`. Перевірте, що термінал відкритий у теці з `requirements.txt`. Не використовуйте інший глобальний `pip`.

### Не знайдено `.venv` або виконуваний файл Python у ній

Виконайте команду створення середовища з кроку 3 у теці проєкту. У Windows перевірте наявність `.venv\Scripts\python.exe`, а в macOS/Linux — `.venv/bin/python`.

### PowerShell повідомляє, що запуск сценаріїв заборонено

Для цієї інструкції не потрібно запускати сценарій активації. Виконуйте команди через `.\.venv\Scripts\python.exe`, як показано вище; змінювати політику PowerShell не потрібно.

### Браузер не підключається або порт 5000 вже зайнятий

Не закривайте термінал із сервером і відкрийте саме адресу `http://127.0.0.1:5000`. Якщо порт 5000 вже використовує інша копія гри, зупиніть її клавішами **Ctrl+C** у відповідному терміналі та запустіть застосунок знову.

### Не вдається встановити пакети

Перевірте підключення до інтернету та повторіть команду встановлення з кроку 3. Якщо шкільна мережа блокує завантаження пакетів, зверніться до вчителя або адміністратора мережі.

## Короткий контрольний список

- Термінал відкритий у теці з `requirements.txt`.
- Доступний Python версії 3.11 або новішої.
- Середовище `.venv` створене, пакети встановилися без помилок.
- У терміналі сервера відображається `Running on http://127.0.0.1:5000`.
- Гра відкривається за адресою `http://127.0.0.1:5000`.
